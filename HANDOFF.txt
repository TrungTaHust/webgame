THÔNG TIN KỸ THUẬT QUAN TRỌNG
--------------------------------------------------------------------------------

THÔNG TIN PATCH EBF5 (đã thực hiện):
- File patch: Options.as — đổi 2 dòng:
    * enableSols: false → true     (dùng SharedObject thay vì .meow files)
    * applicationFeatures: true → false  (bỏ qua AIR wrapper hoàn toàn)
- EBF5 dùng LocalConnection để nói chuyện với AIR wrapper → trên web không có
  wrapper nên game đơ khi save. Patch này cho game dùng SOL save ngay từ đầu.
- Source export còn lại: webgame/ebf5_src/

THÔNG TIN PATCH EBF4 (đã thực hiện):
- Tool dùng: JPEXS Free Flash Decompiler v26.5.0 tại webgame/ffdec/ffdec-cli.exe
- Export source: ffdec-cli.exe -export script <outDir> <swf>
- Import patch: ffdec-cli.exe -importScript <swf> <swf> <patchDir>
- File đã patch:
    * AppFeatures.as — xóa toàn bộ AIR API, stub save/load về no-op
    * Backgrounds.as — thay nativeWindow.bounds bằng stage.stageWidth/Height
- Source export còn lại: webgame/ebf4_src/ (có thể dùng để debug tiếp)
- EBF5 không có AIR API trong source → test trực tiếp không cần patch
  window.RufflePlayer = window.RufflePlayer || {};  // phải đặt TRƯỚC script tag
  <script src="ruffle/ruffle.js"></script>
  
  window.addEventListener('DOMContentLoaded', () => {
    const ruffle = window.RufflePlayer.newest();
    const player = ruffle.createPlayer();
    container.appendChild(player);
    player.ruffle().load({ url: 'path/to/game.swf', autoplay: 'on', ... });
  });

LƯU Ý: KHÔNG dùng customElements.whenDefined('ruffle-player') — không hoạt động
LƯU Ý: KHÔNG dùng CDN unpkg cho Ruffle — đã thử, không hoạt động ổn định

VIỆC CẦN LÀM TIẾP THEO
--------------------------------------------------------------------------------

OPTION A — PATCH SWF BẰNG JPEXS (RECOMMENDED để giữ bản Steam đầy đủ)
  Mục tiêu: xóa/stub các AIR class khỏi SWF để Ruffle có thể chạy

  Bước 1: Tải JPEXS Free Flash Decompiler
    https://github.com/jindrapetrik/jpexs-decompiler/releases
    → tải file ffdec_X.X.X_install.exe, cài vào máy

  Bước 2: Mở file SWF trong JPEXS
    File → Open → chọn game/Epic Battle Fantasy 4.swf

  Bước 3: Với EBF4, cần fix 2 lỗi chính:
    Lỗi 1: "Class flash.display::Screen could not be found — at Main()"
      → Tìm class Main trong Scripts
      → Tìm dòng import flash.display.Screen; → xóa
      → Tìm chỗ dùng Screen class → xóa hoặc comment out

    Lỗi 2: "flash.filesystem::File — at AppFeatures$/loadOptions()"
      → Tìm class AppFeatures trong Scripts
      → Method loadOptions() — đây là hàm đọc save file từ ổ đĩa
      → Xóa toàn bộ body của loadOptions() hoặc return sớm
      → Tương tự với SaveMenu$/loadMeowOptions()

  Bước 4: Với EBF Collection:
    Lỗi: NativeApplication is not defined — at Main/init()
    Lỗi: HTMLLoader — at Main/clickPlay()
      → Tìm class Main, method init() → xóa các dòng dùng NativeApplication
      → Tìm method clickPlay() → xóa/stub phần dùng HTMLLoader

  Bước 5: Với EBF5 — tương tự, cần tìm và stub các AIR class
    (chưa chạy để lấy lỗi cụ thể, chạy thử trên Ruffle để xem console error)

  Bước 6: Export lại SWF từ JPEXS → Save as → ghi đè vào game/*.swf
  
  Bước 7: Test lại trên Live Server

  LƯU Ý KHI PATCH:
  - Chức năng save/load dùng flash.filesystem.File sẽ bị mất
    → Thay thế bằng SharedObject (Flash's built-in save = localStorage tương đương)
    → Ruffle support SharedObject và lưu vào browser storage
  - NativeApplication dùng để detect fullscreen, exit app → có thể xóa an toàn
  - flash.display.Screen dùng để lấy kích thước màn hình → thay bằng stage.stageWidth

DEPLOY LÊN NETLIFY (khi game đã chạy được)
--------------------------------------------------------------------------------
  Vercel KHÔNG phù hợp vì giới hạn 100MB/file → EBF4 (164MB) và EBF5 (288MB) 
  không upload được.

  Dùng NETLIFY:
  1. Vào https://app.netlify.com/drop
  2. Kéo thả toàn bộ thư mục webgame/ vào trang đó
  3. Chờ upload (~vài phút do file nặng)
  4. Nhận link xxx.netlify.app — DONE

  Netlify free plan: không giới hạn file size, 100GB bandwidth/tháng.

  vercel.json trong project không cần thiết cho Netlify, nhưng để lại cũng không sao.
  Nếu dùng Netlify, có thể tạo thêm file netlify.toml để set headers:
    [[headers]]
      for = "/game/*.swf"
      [headers.values]
        Content-Type = "application/x-shockwave-flash"
